# Install this patch

Copy the contents of this folder into the current Discover Corralejo project and choose **Replace files**.

Then unregister the previous service worker, clear site storage, reload, and update the offline tour.

This patch changes:

- `stop.html`
- `css/platform-polish.css`
- `service-worker.js`
- `docs/NONSTICKY_COMPACT_HEADERS_2026-08-03.md`
