# Light-default and welcome-page theme update

- The welcome/language page is permanently rendered in the approved light visual treatment.
- No light/dark theme button is created on the welcome page.
- All other pages default to light mode when the user has not made a choice.
- A dark-mode choice made from the route, stop, completion, or feedback pages is still saved and respected on those pages.
- Device/system dark mode no longer changes the app automatically.
- Service-worker cache version: `v19-light-default-no-home-toggle`.
